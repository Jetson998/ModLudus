# ModLudus 执行计划

## M0（当前）

完成产品验收页面、项目骨架、配置模板和 API 健康检查。

## M1（1–2 周）

接入通用 OpenAI-compatible endpoint，完成模型发现、连接测试、候选并行调用和运行记录。

## M2（2 周）

完成匿名 A/B、独立裁判、人工抽检、价格快照和质量/成本/速度结果卡。当前 M1 已具备单次人工复核标记与低置信度提示；批量抽检队列仍属于真实试点阶段。

## M3（2–3 周）

加入 CSV/JSONL 测试集、Rubric 版本、批量运行、复核队列、基线对比和报告导出。

## M4（后续）

接入 EvalScope、回归门禁、权限、脱敏、审计、备份恢复和正式 HTTPS 部署。
